The owner's standing ruling for the USB loop (2026-11-23): after U3-U, clean iterates USB on one branch without a new prompt or PR per try. For each try, clean runs only the USB seams cases (plus report1 when the identity changes), packs an owner-only file, and the owner flashes it after the check. Unit observations go to clean through the owner. Clean keeps to: writes sourced in HW-172 or HW-178 only; no writes to 0x16A00 or any clock register; owner-only files; R-USB-1. Anything needing a new source stops the loop and comes to you and the owner. Tunable values (the port spacing first) may be offered as test-screen choices, so one flash tries several. When USB works: one PR with full CI, your HARDWARE-SPEC entries in one batch, and a full unit run as the backtest. Save this with spec/u3u-rulings.
